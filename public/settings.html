How keys are stored

Keys are written to a file on the server with owner-only permissions (0600), kept out of git, and never sent to the browser — this page only ever shows a masked preview. The file is not served over HTTP, so its name and location are not printed here.

A key set in .env stays in effect if you remove it here. Saving a key here applies immediately; no restart needed.
